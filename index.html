GitHub API Token (BL-19)

        
Your Personal Access Token allows this form to commit changes directly to the board - no copy-paste needed. The token is stored only in this browser session and never sent anywhere except GitHub's API.

To create one: GitHub -> Profile -> Settings -> Developer settings -> Personal access tokens -> Tokens (classic) -> Generate new token -> tick repo scope.
